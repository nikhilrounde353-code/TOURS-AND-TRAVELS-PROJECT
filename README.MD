# MANASI TOURS AND TRAVELS

## Project Overview

MANASI TOURS AND TRAVELS is a simple Python-based travel management application developed as a student project.

The project helps a small travel company manage tour packages, tour bookings and car rentals through a menu-driven Python program.

The project is made using basic Python concepts such as lists,functions, loops, conditional statements, input/output and modules.

## Features

The project provides the following features:

1. View Tour Packages
2. Book a Tour
3. Tour Payment
4. Car Rental
5. Car Rental Payment
6. View Bookings
7. Search Booking
8. Cancel Booking
9. View Car Rental Records
10. Exit

### Payment Options

The project provides simple payment selection:

- UPI
- Cash
- Card

This is a simulated payment option for the project and does not perform any real financial transaction.

## Technologies Used

- Python
- Visual Studio Code
- Git and GitHub
No external Python libraries are required.


## How to Run

1. Open the project folder in Visual Studio Code.
2. Open the terminal.
3. Run the following command:
python main.py
4. The main menu will appear.
5. Select an option by entering its number.

# Limitations
- Booking and rental records are stored temporarily while the program is running.
- Data is not stored permanently.
- Payment is simulated.
- The project is command-line based.
