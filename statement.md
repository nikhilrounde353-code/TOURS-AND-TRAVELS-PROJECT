# Project Statement

## Problem Statement

Small travel companies need to manage tour packages, customer bookings and car rentals in an organized way. Managing these activities manually can take more time and may cause mistakes.

This project provides a simple Python-based system for managing tour,bookings and car rentals through a menu-driven application.

## Scope of the Project

The project focuses on basic travel management activities.

The system allows users to:

- View available tour packages
- Book a tour
- Select a payment method for a tour
- Rent a car
- Select a payment method for a car rental
- View booking records
- Search for a booking
- Cancel a booking
- View car rental records

The project is designed as a basic command-line Python application.

## Target Users

The main target users are:

- Small travel company staff
- Travel company owners
- Customers who want to book tours or rent cars

## High-Level Features

1. Tour Package Management
2. Tour Booking
3. Tour Payment Selection
4. Car Rental
5. Car Rental Payment Selection
6. Booking Search and Cancellation
7. Booking and Rental Record Viewing
